# Weather-Advisory Support Bot

A production-minded, auditable Weather-Advisory Support Bot backed by a deterministic-first LangGraph state machine.

## Core Architectural Principle
> **The LLM interprets intent and verbalizes decisions. Deterministic application code owns facts, weather normalization, policy matching, severity resolution, and safety decisions.**
